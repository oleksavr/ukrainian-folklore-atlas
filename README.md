# Dyvosvit — Ukrainian Folklore Atlas

A small, bilingual, mobile-friendly folklore explorer. Search eight figures, filter them by realm, switch between English and Ukrainian, and open a short story with further-reading links.

Play it at **https://oleksavr.github.io/ukrainian-folklore-atlas/**

On an iPhone, open that link in Safari and choose Share → Add to Home Screen if you want it on your home screen.

## Run it

No build tools or dependencies are needed. Open `index.html` in a browser, or use the GitHub Pages link above.

The app is a static site, so it also works on any ordinary static host.

## Customize

All app content, styles, and interactions are in `index.html`. Creature summaries are paraphrased and linked to sources in the app. The collection emphasizes regional variation; it is an introduction to recorded traditions, not a claim that supernatural beings exist.
